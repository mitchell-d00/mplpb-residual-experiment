# The Residual of Logic

Mitchell D. McPhetridge. Revised 11 November 2026.

- [PDF](The_Residual_of_Logic.pdf)
- [Markdown source](The_Residual_of_Logic.md)

The Markdown file is canonical. The rewrite incorporates the executed fourteen
fixture pilot, all five measured metrics, the conventional baseline, the two
Arc papers, and the public self-reference chain with real identifiers and seals.
It distinguishes documented correction of the writer's claims from executable
technical revision, and reports the baseline's agreement with MPLPB.

The evidence is retained in [results/pilot-1](../results/pilot-1/).
The paper's source implementation is pinned to upstream commit
`257e54a51edac272eb6b2441457f38a40485ee4d`. Upstream source is not modified.

## Build

Run `python3 paper/build.py` from the repository root. It requires Pandoc,
ReportLab, and DejaVu fonts under `/usr/share/fonts/truetype/dejavu`.
The experiment runner itself has no third-party dependencies.

The retained PDF was checked for expected metrics and source identifiers,
text within page bounds, and representative page rendering. The short results
table is kept together. All three formats derive from the same Markdown.

Direct downloads of the two Arc records were blocked during this review.
The manuscript states its reliance on indexed primary-source record text;
no historical ledger seals for those papers are invented.
